# local/ — собственный код FORKEL

Весь код проекта хранится здесь (решение DEC-DEV-10, `docs/development/requirements/DISC-12-open-questions-and-decisions.md`).
Ядро Битрикса (`backend/www/bitrix/`) в репозиторий не попадает и не правится.

## Состав

| Путь | Назначение |
|---|---|
| `templates/forkel/` | Шаблон сайта: `header.php`, `footer.php`, `template_styles.css`, `js/app.js` |
| `components/` | Собственные компоненты и шаблоны компонентов (по мере появления) |
| `php_interface/` | `init.php` и обработчики событий (по мере появления) |

## Подключение шаблона (один раз, вручную)

Шаблон нужно выбрать в административной части, из кода это не делается:

1. Откройте административную часть Битрикса.
2. Настройки → Настройки продукта → Сайты → Список сайтов → ваш сайт → поле «Шаблоны сайта» (или Настройки → Сайты → Шаблоны сайта в вашей редакции — расположение пунктов зависит от версии).
3. Добавьте шаблон `forkel` без условий и поставьте его выше остальных.
4. Сбросьте кеш.

Если шаблон `forkel` не виден в списке, проверьте, что файл `templates/forkel/description.php` лежит именно в `backend/www/local/templates/forkel/`.

## Стили и скрипты

`template_styles.css` и `js/app.js` созданы из `prototype/homepage-v3` скриптом
`backend/scripts/sync-template-from-prototype.sh` (запускается один раз). Дальше правки вносятся в шаблон.
`template_styles.css` Битрикс подключает автоматически через `$APPLICATION->ShowHead()` в `header.php`.

## Что в шаблоне временное

- Меню и подвал статические (демонстрационные тексты, DEC-DEV-11); меню переводится на компонент отдельной задачей.
- Счётчик корзины не подключён: в прототипе он работал на `localStorage`, в Битриксе его заменит компонент корзины.
- Ссылки `/catalog/`, `/personal/`, `/personal/cart/`, `/search/`, `/about/contacts/`, `/about/delivery/` ведут на страницы демо-сайта «Малый бизнес».
