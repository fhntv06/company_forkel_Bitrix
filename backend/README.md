
# FORKEL — Backend и локальное окружение

Docker-окружение для локального развёртывания сайта FORKEL на 1С-Битрикс.

## 1. Состав окружения

- **Nginx** — HTTP-сервер, порт `8080` на хосте.
- **PHP-FPM** — выполнение PHP-кода сайта.
- **MySQL 8.0** — база данных.
- **Docker Compose** — запуск и управление сервисами.

Конфигурация рассчитана на локальную разработку. Перед использованием в production необходимо проверить требования выбранной редакции 1С-Битрикс и отдельно настроить HTTPS, безопасность, резервное копирование и секреты.

## 2. Структура каталогов

```text
backend/
├── docker-compose.yml
├── .env.example
├── .env
├── README.md
├── docker/
│   ├── php/
│   │   ├── Dockerfile
│   │   └── php.ini
│   └── nginx/
│       └── default.conf
└── www/
```

Каталог `www/` — корень сайта, который доступен Nginx внутри контейнера по пути `/var/www/html`.

## 3. Требования

На компьютере должны быть установлены:

- Docker Engine или Docker Desktop;
- Docker Compose v2 (`docker compose`);
- Git.

Перед установкой проверь системные требования своей версии 1С-Битрикс. Используемые сейчас PHP 8.2 и MySQL 8.0 — предварительные версии окружения, а не подтверждение совместимости с конкретной редакцией продукта.

## 4. Подготовка окружения

Перейди в каталог `backend/`:

```bash
cd backend
```

Создай локальный файл переменных окружения:

```bash
cp .env.example .env
```

Открой `.env` и замени демонстрационные значения паролей на собственные.

Переменные MySQL:

| Переменная | Назначение |
|---|---|
| `MYSQL_DATABASE` | Имя базы данных |
| `MYSQL_USER` | Пользователь приложения |
| `MYSQL_PASSWORD` | Пароль пользователя приложения |
| `MYSQL_ROOT_PASSWORD` | Пароль администратора MySQL |

Файл `.env` содержит секреты и не должен попадать в Git.

## 5. Подготовка файлов сайта

Создай каталог `www/`, если он ещё не существует:

```bash
mkdir -p www
```

Для установки Битрикс помести официальный установочный скрипт `bitrixsetup.php` в каталог `www/`.

Получай установочные файлы только из официальных источников 1С-Битрикс и проверь актуальные требования к окружению перед запуском.

Не добавляй в Git установленные файлы ядра Битрикс, пользовательские загрузки, кеши, дампы базы и другие локальные данные.

## 6. Проверка конфигурации

Из каталога `backend/` выполни:

```bash
docker compose config
```

Команда проверяет синтаксис и итоговую конфигурацию Compose. Она может показать значения переменных окружения, поэтому не публикуй её вывод, если он содержит секреты.

Если конфигурация корректна, собери PHP-образ и запусти сервисы:

```bash
docker compose up -d --build
```

Проверь состояние контейнеров:

```bash
docker compose ps
```

Посмотри логи при необходимости:

```bash
docker compose logs --tail=100 nginx php db
```

Открой в браузере:

```text
http://localhost:8080
```

Пока установка сайта не завершена, приложение может быть недоступно — это ожидаемо.

## 7. Установка 1С-Битрикс

1. Убедись, что контейнеры запущены и MySQL прошёл healthcheck.
2. Открой `http://localhost:8080/bitrixsetup.php`.
3. Следуй официальной инструкции установщика.
4. Для подключения к базе укажи:
    - **Сервер БД:** `db`
    - **Порт:** `3306`
    - **Имя базы:** значение `MYSQL_DATABASE` из `.env`
    - **Пользователь:** значение `MYSQL_USER` из `.env`
    - **Пароль:** значение `MYSQL_PASSWORD` из `.env`
5. После завершения установки удали `bitrixsetup.php` из публичного каталога `www/`.
6. Проверь работу сайта и логи контейнеров.

Имя сервера БД — `db`, потому что это имя сервиса MySQL во внутренней сети Docker Compose. Подключаться к нему из установщика через `localhost` не нужно.

## 8. Основные команды

Запустить окружение:

```bash
docker compose up -d
```

Пересобрать PHP-образ и запустить окружение:

```bash
docker compose up -d --build
```

Остановить контейнеры:

```bash
docker compose stop
```

Остановить и удалить контейнеры, сохранив именованный том базы:

```bash
docker compose down
```

Посмотреть логи:

```bash
docker compose logs -f
```

Проверить PHP:

```bash
docker compose exec php php -v
```

Посмотреть установленные расширения PHP:

```bash
docker compose exec php php -m
```

Проверить готовность MySQL:

```bash
docker compose exec db sh -c 'mysqladmin ping -h 127.0.0.1 -uroot -p"$MYSQL_ROOT_PASSWORD" --silent'
```

## 9. Данные и резервное копирование

База данных хранится в именованном Docker-томе `mysql_data`.

Команда `docker compose down` сохраняет этот том. Однако удаление тома, очистка Docker-данных или сбой диска могут привести к потере информации.

**Не выполняй `docker compose down -v` без осознанного решения удалить данные базы.**

Перед важными изменениями делай резервную копию базы данных и храни её вне репозитория.

## 10. Безопасность

- Не коммить `.env`, пароли, токены и дампы базы.
- Не публикуй MySQL-порт в интернет.
- Не используй демонстрационные пароли вне локальной среды.
- Не оставляй `bitrixsetup.php` в публичном каталоге после установки.
- Не используй эту конфигурацию как готовую production-среду без дополнительной проверки.
- Перед публичным запуском настрой HTTPS, права доступа, резервное копирование, журналирование и обновления компонентов.

## 11. Ограничения текущего этапа

Это базовое локальное окружение. Оно само по себе не содержит кода сайта, ядра 1С-Битрикс, каталога товаров или интеграции с 1С.

Перед фактической установкой необходимо проверить совместимость версий PHP и MySQL, набор расширений и дополнительные требования конкретной редакции Битрикс.
