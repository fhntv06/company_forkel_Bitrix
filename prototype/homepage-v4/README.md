# FORKEL — прототип V4

Главная V4 (`index.html`) и переход страниц и функций V3 в дизайн V4. План: `docs/design/v3-to-v4-migration.md`; задача PRT-003.

**Запуск:** `python3 -m http.server 8081 --directory prototype`, затем `http://localhost:8081/homepage-v4/index.html`. Без сборки и зависимостей.

## Структура

| Путь | Назначение |
|---|---|
| `styles.css` | токены и компоненты V4 (источник дизайна; шрифт Montserrat) |
| `css/v4-skin.css` | слой оформления: токены V3 `--fk-*` → токены V4. Подключается после `styles.css` и компонентов V3 |
| `data.js` | данные V3 без изменений (`FKData`); пути картинок — `assets/images/` |
| `assets/images/` | изображения V3 (слои подбора — только референс; `solutions/`, `designs/` — материалы заказчика) |
| `assets/fonts/` | Montserrat (OFL) |
| `css/header.css`, `site.js` | шапка V4 с функциями V3 (M2): каталог-панель, мобильное меню, счётчики, заглушки; точка перехода 1100 px |
| `cart.js`, `favorites.js`, `auth.js` | логика V3 без изменений (M4): корзина, избранное, вход-демо; ключи `fk-demo-cart-v1`, `fk-demo-fav-v1`, `fk-demo-auth-v1` |
| `css/shared.css` | общие компоненты V3 в стиле V4: `fk-btn`, `fk-link`, `fk-tag`, `fk-chip`, тона плиток, графика изделий (`pl-*`, `fin-*`); спрайт изделий лежит в `page-template.html` |
| `search.js`, `css/search.css` | окно поиска (M5): логика V3 без изменений |
| `feedback.js`, `css/feedback.css` | окно обратной связи (M6): логика V3 без изменений; поля формы — в `css/shared.css`; кнопки-вызовы — `[data-feedback]` |
| `callback.js` | окно «Обратный звонок» (M7): логика V3 без изменений, оформление — `css/feedback.css` (общие классы `fk-fb*`); кнопки-вызовы — `[data-callback]` |
| `css/footer.css`, `social.js` | подвал V4 с функциями V3 (M3) и плавающий виджет соцсетей |
| `page-template.html` | шаблон страницы: шапка (M2) и подвал (M3) — эталонная разметка для всех страниц |
| `configurator.js`, `configurator.css` | подбор (I2): логика и данные V3 без изменений, вид V4; css лежит в корне — `--img: url(assets/…)` считается от него |
| `css/products.css`, `css/favorites.css` | карточка товара V3 (`products.css` идентичен V3, вид — через токены `v4-skin.css`) и кнопка-сердце; «Новинки» главной используют их (I3) |
| `css/projects.css`, `css/solutions.css`, `css/interiors.css`, `solutions.js` | «Проекты», «Готовые решения» (нативный слайдер), «Интерьеры» (I4): идентичны V3, вид — через токены `v4-skin.css` |
| `collection.html`, `shop.js`, `css/page.css`, `css/catalog.css`, `css/categories.css`, `css/collections.css` | страница коллекции (P2) и общий движок каталога V3 без изменений; P1/P3/P4 используют его же; порядок CSS как в V3 |
| `new.html` | страница «Новинки» (P3): 8 демо-товаров, тот же движок `shop.js` и css, что у коллекции |
| `app.js` | поведение главной V4 (на страницах без подбора и «Новинок» не падает) |

## Выполнено

- M0 — эталон главной (`prototype/tools/parity/baseline/`).
- M1 — каркас: папки, `data.js`, изображения, `css/v4-skin.css`, шаблон страницы.
- M2 — шапка (в шаблоне; на главную V4 подключается на этапе I1, чтобы эталон M0 оставался неизменным).
- M3 — подвал (в шаблоне; на главную подключается на I1).
- M4 — корзина, избранное, авторизация (логика и счётчики; новых экранов нет).
- M5 — окно поиска.
- M6 — окно обратной связи.
- M7 — окно «Обратный звонок». Группа M завершена.
- I1 — главная подключена к общим шапке, подвалу и скриптам; `app.js` главной оставил только подбор и карточки новинок (меню и заглушки — `site.js`).
- I2 — подбор на главной: компонент V4, палитры F70/F55, слои изображений и логика V3, комплект в корзину, ссылка на страницу подбора.
- I3 — «Новинки»: 5 карточек V3 (избранное, корзина, цветовые точки) в стиле V4; прокрутка на 360–390 px исправлена; направления — три категории, остальные в меню шапки.
- I4 — на главной после «Новинок»: «Проекты», «Готовые решения», «Интерьеры» (разметка и данные V3, вид V4).
- P2 — страница коллекции (`collection.html`): баннер, переключатель F70/F55, ссылка в подбор, фильтры и карточки V3; выполнена по указанию владельца раньше P1.
- P3 — страница «Новинки» (`new.html`): 8 демо-товаров, фильтры, карточки V3; выполнена по указанию владельца раньше P1.
