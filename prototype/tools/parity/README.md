# Проверки паритета FORKEL

Скрипты Playwright (Python, Chromium) для проверки прототипов на 7 ширинах (360, 390, 768, 1024, 1280, 1440, 1920 px): нет горизонтальной прокрутки и ошибок JS, цели нажатия, сценарии функций.

## Запуск

```
python3 -m http.server 8081 --directory prototype      # из корня репозитория
pip install playwright && playwright install chromium   # один раз
python3 -I prototype/tools/parity/favorites_header.py
```

Переменные: `FK_BASE` — адрес версии (по умолчанию `http://localhost:8081/homepage-v3/`, для V4 — `.../homepage-v4/`), `FK_OUT` — папка скриншотов (по умолчанию `/tmp/`). Скрипт печатает `OK` или список отклонений.

| `favorites_header.py` | избранное: сердце в карточках, счётчик в шапке, страница, очистка; шапка без горизонтальной прокрутки |

| `solutions.py` | «Готовые решения»: слайды 0.8, точки, блок товаров внутри слайда, стрелки и пагинация (долго, до 5 мин) |
| `product_code.py` | строка «Код» над артикулом: порядок, цель нажатия, копирование в буфер |
| `footer_social.py` | подвал: положение блока соцсетей (печатает геометрию, без вердикта) |
| `baseline_v4.py` | эталон главной V4 (M0; обновлён на I1 — общие шапка и подвал): `--save` пишет `baseline/v4-index-{ширина}.jpg`, без флага сравнивает (порог 0.2% пикселей) |

| `search_v4.py` | V4, M5: окно поиска — открытие мышью и клавиатурой, подсказки, результаты с графикой изделий, проекты, пустой результат, очистка, модальный фокус, Esc, подложка, геометрия на 7 ширинах, переход на `search.html?q=` |
| `feedback_v4.py` | V4, M6: окно «Написать нам» — геометрия на 7 ширинах, проверка полей и сводка ошибок, фокус, Esc, подложка, имитация отправки без запросов и без хранения данных |
| `callback_v4.py` | V4, M7: окно «Обратный звонок» — геометрия на 7 ширинах, телефон и согласие, выбор времени, фокус, Esc, имитация отправки без запросов и хранения, независимость от окна обратной связи |

Это проверки текущей V3; по плану `docs/design/v3-to-v4-migration.md` (раздел 6) их запускают против V4 после каждого этапа и дописывают новые. Скрипты вспомогательные, не часть сайта; зависимостей в прототипы не добавляют.
