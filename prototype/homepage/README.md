# Прототип главной FORKEL

Визуальный прототип по `docs/design/homepage-spec.md` и `docs/design/design-system.md` (v0.1). Нужен, чтобы оценить композицию, типографику, сетку и адаптивность до интеграции с 1С-Битрикс. **Это не шаблон Bitrix и не рабочий сайт.**

## Запуск

Сборка и зависимости не нужны: это статические HTML, CSS и JS.

Вариант 1 — открыть файл в браузере:

```
prototype/homepage/index.html
```

Вариант 2 — локальный сервер (любой из установленных):

```bash
python3 -m http.server 8080 --directory prototype/homepage
# затем открыть http://localhost:8080
```

```bash
npx serve prototype/homepage
```

Для просмотра адаптивности откройте инструменты разработчика и проверьте ширины 360, 768, 1024, 1440 px.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Разметка блоков H-01…H-04, H-07, H-08, H-09, SVG-спрайт изделий |
| `styles.css` | Токены `--fk-*` из дизайн-системы и стили компонентов `.fk-*` |
| `app.js` | Меню, панель каталога, пояснения для неработающих элементов |

## Что в прототипе временное

- Названия коллекций («Коллекция A…H») и категорий («Категория D…F»), тексты блоков, цвета образцов изделий. Розетки, выключатели и рамки названы в требованиях проекта.
- Изображения нарисованы в SVG: это иллюстрации, не фото продукции.
- Логотип: текстовая заглушка «FORKEL». Контакты, реквизиты, политика ПДн, условия доставки отсутствуют: на их месте пояснения.
- Блок «Доставка и оплата» в рабочем сайте скрывается, пока владелец не утвердит способы (спецификация, H-08).

## Что не работает (намеренно)

Поиск, личный кабинет, корзина, страницы коллекций и категорий, политика ПДн. Кнопки и ссылки на них показывают короткое пояснение внизу экрана. Счётчика корзины, телефона и формы нет. Ссылки внутри страницы (якоря) работают.

## Отличия от спецификации

- Поиск, кабинет и корзина показаны для оценки шапки, хотя по правилу R1 в рабочем сайте их не выводят без работающей функции.
- Вторичная кнопка первого экрана («Собрать в подборе») не выводится: конфигуратор не готов.
- Блоки очереди B (подбор, товары, проекты) не реализованы.
- Шрифт Golos Text не подключён: файлы шрифта недоступны в среде. Работает системный стек из дизайн-системы (4.2). Для подключения нужны проверка лицензии и локальное размещение файлов.
- Первый экран до 767 px: фото 4:3 по спецификации (H-02). На 360×640 кнопка заканчивается на 631 px из 640. Баннер «Прототип…» на этих ширинах вынесен вниз страницы, чтобы не занимать первый экран; на 768 px и шире он вверху.
- 768–1023 px: формат фото для планшета в спецификации не задан; сохранена высота `clamp(320px, 62vw, 560px)`. Вопрос открыт (см. `handoff.md`).
- Блок «Доставка и оплата» помечен в макете как условный (`data-proto-status="conditional"`), тексты блока «Профессионалам» заменены явными временными. Заголовок «Дизайнерам и архитекторам» заменён на «Дизайнерам»: в H-07 перечислены дизайнеры, монтажники и дилеры.
- Без JavaScript навигация выводится списком ссылок; иконки и меню скрыты.

## Проверка

Проверено 2026-10-16 в headless Chromium (Playwright) через `python3 -m http.server`: ширины 360, 768, 1024, 1280, 1440 px; клавиатура и фокус; меню и панель каталога; якоря; режимы без JavaScript и `prefers-reduced-motion`. Не проверялись реальные устройства, Safari, Firefox, скринридеры, скорость. Подробности — `docs/workflow/handoff.md`, раздел 6.

## Поведение

- Панель каталога (от 1024 px): открывается по клику, `Enter` и `Пробел`; закрывается `Esc`, повторным кликом, кликом снаружи; по наведению не открывается.
- Мобильное меню (до 1024 px): полноэкранная панель, прокрутка страницы заблокирована. При открытии фокус переходит на первый пункт панели; `Tab` и `Shift+Tab` обходят шапку и панель по кругу в визуальном порядке, остальная страница недоступна (`inert`). Закрывается кнопкой и `Esc`, фокус возвращается на кнопку меню.
- Анимация одна: появление изображения первого экрана (400 мс). При `prefers-reduced-motion` отключена.
