# FORKEL — Hero (концепт)

Изолированный первый экран главной. Не меняет `prototype/homepage` и `prototype/homepage-v2`.

**Открыть:** двойным кликом по `index.html` (сервер и сборка не нужны).

**Файлы:** `index.html` (демо-страница, заглушка шапки и сам Hero), `hero.css` (стили, всё внутри `.fk-hero`), `hero.js` (демо-выбор отделки, слот под фото).

**Подключить к другим страницам:** перенести секцию `<section class="fk-hero">` из `index.html`, подключить `hero.css` и `hero.js`.

**Что временное:** изображение — условная векторная визуализация, не фотография и не данные изделий; названия отделок взяты с forkel.by и помечены «демо». Оранжевый акцент замерен по кнопкам forkel.by, бренд-цвет не утверждён. Шрифт Golos Text не подключён, работает системный стек. Заглушка шапки в `index.html` не часть компонента.

**Реальное фото:** в `<section class="fk-hero">` задайте `data-photo="assets/hero.jpg"` и `data-photo-alt="описание"`: фото заменит визуализацию, добавится затемнение под текст.

**Проверено (Chromium, 360 / 768 / 1024 / 1440 px):** нет горизонтальной прокрутки, нет ошибок в консоли, Tab и стрелки по группе отделки работают, фокус виден, при `prefers-reduced-motion` появление отключено. **Не проверялось:** Safari и Firefox, реальные устройства, скорость загрузки.
