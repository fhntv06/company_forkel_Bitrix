# FORKEL — прототип V3 (в работе)

Самостоятельная версия на основе `prototype/homepage-v2/` (V2 не изменяется). Собирается поэтапно: один блок, карточка или секция за коммит; после каждого коммита — просмотр и правки либо приёмка. Задача — UI-011 в `docs/workflow/task-queue.md`, критерии — `docs/qa/acceptance-checklist.md`.

**Запуск:** `python3 -m http.server 8080 --directory prototype`, затем `http://localhost:8080/homepage-v3/index.html`. Общие изображения лежат в `prototype/assets/images/`. Без сборки и зависимостей.

## Блок 1 — Hero

Взят из `prototype/hero/` (`hero.css`, `hero.js`, разметка секции) без изменения вида. Правки только для интеграции: убраны глобальные правила исходного CSS (reset, `body`, `h1`, `.fk-vh`), класс образцов переименован в `.fk-hero__swatches` (в `styles.css` есть `.fk-swatches` подбора), анимации — в `fk-hero-fade` и `fk-hero-rise`, блок ограничен шириной 1440 px по центру; старый Hero V2 и его стили удалены. ## Структура стилей

`styles.css` — токены, общие правила и страницы; компоненты лежат в `css/` по одному файлу на блок и подключаются через `@import` в начале `styles.css`: `css/header.css` (H-01), `css/hero.css` (H-02). Новые блоки добавляются так же.

## Новое направление дизайна V3

Крупные элементы и воздух; светлый сайт; у элементов фон; скругления; премиальный вид; контраст и яркие акценты. Решения владельца: акцент — золотой `#D2B473` (`--fk-bright`, текст на нём `#1E2022`; заменил оранжевый, в том числе в Hero); контейнер сетки (`.fk-container`, Hero) расширен с 1440 до 1920 px; шапка ограничена сеткой так же, как контент; между шапкой и Hero ровно 16 px. Токены в `styles.css`: `--fk-r-md` 14px, `--fk-r-lg` 24px, `--fk-tint` #EEF1F5 (радиусы и фон шапки — предложение, на согласование). Акцент применён: «Каталог»/«Меню», счётчик корзины, основные кнопки `.fk-btn--primary`, подчёркивание `.fk-link`, кнопка Hero.

H-01 (v3): полоса шапки прозрачная, карточка с фоном и скруглением 24px лежит внутри контейнера по сетке; строка 72 px (мобильные) / 96 px (от 1024); `--fk-header-h` = 96/120 с учётом отступов 8 сверху и 16 снизу; панель каталога — скруглённая карточка по сетке; телефон-заглушка от 1536px.
