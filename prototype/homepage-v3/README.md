# FORKEL — прототип V3 (в работе)

Самостоятельная версия на основе `prototype/homepage-v2/` (V2 не изменяется). Собирается поэтапно: один блок, карточка или секция за коммит; после каждого коммита — просмотр и правки либо приёмка. Задача — UI-011 в `docs/workflow/task-queue.md`, критерии — `docs/qa/acceptance-checklist.md`.

**Запуск:** `python3 -m http.server 8080 --directory prototype`, затем `http://localhost:8080/homepage-v3/index.html`. Общие изображения лежат в `prototype/assets/images/`. Без сборки и зависимостей.

## Блок 1 — Hero

Взят из `prototype/hero/` (`hero.css`, `hero.js`, разметка секции) без изменения вида. Правки только для интеграции: убраны глобальные правила исходного CSS (reset, `body`, `h1`, `.fk-vh`), класс образцов переименован в `.fk-hero__swatches` (в `styles.css` есть `.fk-swatches` подбора), анимации — в `fk-hero-fade` и `fk-hero-rise`, блок ограничен шириной 1440 px по центру; старый Hero V2 и его стили удалены. Кнопки ведут на `#collections` и `#configurator`.

На согласование (решения не приняты): оранжевый акцент кнопок Hero (замерен у forkel.by, остальной сайт монохромный; D10); названия отделок Hero («Никель» и др.) не совпадают с шестью цветами подбора; изображение — векторная визуализация, фото нет (слот `data-photo` в секции готов).

## Структура стилей

`styles.css` — токены, общие правила и страницы; компоненты лежат в `css/` по одному файлу на блок и подключаются через `@import` в начале `styles.css`: `css/header.css` (H-01), `css/hero.css` (H-02). Новые блоки добавляются так же.

## Блок 2 — H-01 Шапка сайта

Стили шапки, навигации, панели каталога, мобильного меню, телефона-заглушки, баннера прототипа и счётчика корзины вынесены из `styles.css` в `css/header.css` без изменения вида. Правки: кнопка поиска — поле «Поиск по товарам» от 1440 px (до 1440 px иконка), `aria-haspopup="dialog"`, доступное имя «Поиск по товарам»; на странице корзины иконка корзины отмечена `aria-current="page"`, на каталоге и товаре подчёркнут пункт «Каталог». Разметка шапки одинакова на `index`, `catalog`, `product`, `cart` (различаются только префиксы якорей `index.html#…`).

Не сделано, ждёт следующих блоков: окно поиска (кнопка пока показывает уведомление), страницы проектов и контактов (пункты ведут к якорям главной), судьба кнопки личного кабинета (нет страницы; кнопка показывает уведомление) — вопрос владельцу.
