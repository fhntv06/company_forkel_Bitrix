## 5. Требуемый результат

### 5.1. Страница «Контакты»

1. Удалить баннерную композицию: фон/обёртку баннера, фотографию, надпись FORKEL и подпись «Способы связи с FORKEL.».
2. Сохранить один обычный h1 «Контакты» с `id="ct-title"`, оформить в стиле заголовков страниц и выровнять по сетке контента.
3. Порядок: существующие хлебные крошки → h1 «Контакты» → блоки контактной информации. Не оставлять пустое место высотой бывшего баннера.
4. Удалить h2 «Связь» из разметки, а не просто скрыть его визуально.
5. Исправить ссылку `aria-labelledby="ct-conn"` после удаления заголовка: использовать существующий заголовок либо подходящую структуру без висячего IDREF. Привести уровни заголовков карточек к последовательной иерархии.
6. Сохранить данные, ссылки, кнопки «Написать нам» / «Заказать звонок», карту и реквизиты. Не менять порядок прямых детей `.fk-ct` без проверки позиционных CSS-правил.
7. Не менять общие правила `.fk-ab-hero`, влияющие на другие страницы.

### 5.2. Четыре карточки «С кем мы работаем»

Заменить содержимое двух существующих карточек четырьмя. Заголовок секции «С кем мы работаем» сохранить.

| № | Заголовок | Описание |
|---|---|---|
| 01 | Выгодные условия сотрудничества | Подберём условия сотрудничества с учётом задач и формата вашего бизнеса. |
| 02 | Увеличенная скидка на образцы | Предоставляем увеличенную скидку на образцы, чтобы вы могли познакомить клиентов с продукцией FORKEL. |
| 03 | Демонстрационные стенды | Поможем представить продукцию FORKEL на демонстрационных стендах в вашем магазине или шоуруме. |
| 04 | Изготовление по индивидуальным размерам | Обсудим изготовление по вашим размерам с учётом требований конкретного проекта. |

- Все четыре карточки имеют видимые номера 01–04, заголовок и короткий абзац.
- Сетка: от 1280 px — четыре равные колонки; 768–1279 px — две; до 767 px — одна. Промежутки и края согласованы с сеткой проекта.
- Сделать карточки компактнее существующих: рекомендуемые ориентиры — padding 20–24 px, внутренний gap 12–16 px, заголовок 20–24 px, описание 16–18 px. Использовать подходящие существующие токены.
- Убрать крупные декоративные иконки; визуальный акцент — номера. Использовать единый стиль всех четырёх карточек.
- Не задавать искусственную минимальную высоту и не растягивать расстояния между элементами. В одном ряду карточки могут иметь одинаковую высоту по самой высокой.
- Длинный заголовок четвёртой карточки переносится естественно. Описания остаются короткими, без обрезки и принудительного ограничения числа строк.
- Новые карточки не интерактивны; кнопки и ссылки не добавлять.

### Допущения

- Запрос включает две страницы V4: контакты и сотрудничество; перенос секции между ними не требуется.
- Четыре новые темы заменяют прежние две карточки, а не добавляются к ним.
- Несмотря на изменение тематики карточек на преимущества, название секции сохраняется по формулировке владельца.
- Сетка 4 → 2 → 1 и отказ от крупных иконок — выбранное решение для требования «четыре маленьких».
- Для индивидуальных размеров не уточнено, какие именно изделия изготавливаются, поэтому текст не сужает тему до стендов или иной продукции.
- Тексты не содержат придуманных процентов скидки, сроков, минимальных объёмов заказа или обещания бесплатных стендов.
