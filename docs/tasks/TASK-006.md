## Допущения
1. Состав: основное фото (детальная картинка, если задана), картинка анонса, затем MORE_PHOTO; одинаковые файлы (по ID) не повторяются. Если детальной нет — полоса начинается с картинки анонса, как вы описали.
2. У торгового предложения (цвета) свой набор фото (его анонс, детальная, MORE_PHOTO); если у предложения фото нет, показывается набор товара. При смене цвета полоса и главное фото обновляются.
3. Если фото меньше двух, полоса скрыта.
4. Миниатюры отдаются размером 240×240 (кроп), для 120 px с запасом на ретину; крупное фото — до 1200 px.
5. Блок и основное фото обёрнуты в `.fk-pdp__gallery` (в сетке `.fk-pdp` он занимает прежние 7 колонок), чтобы полоса стояла сразу под фото.

- [ ] Миниатюры 120×120, стрелки листают, на краях отключены, на узком экране работает свайп.
- [ ] Клик по миниатюре меняет основное фото; активная имеет рамку и `aria-current`.

- [ ] Меньше двух фото — полосы нет; страница без JS показывает полосу без ошибок.
