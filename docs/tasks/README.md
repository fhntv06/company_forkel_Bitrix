# Задачи FORKEL

Каждая задача, поставленная владельцем в чате, оформляется здесь отдельным файлом `TASK-NNN.md` по шаблону `docs/workflow/task-template.md`.

## Как это работает
1. Владелец пишет задачу в чат (можно командой `/task <описание>`).
2. Claude оформляет её в `docs/tasks/TASK-NNN.md`, добавляет запись в `docs/workflow/task-queue.md` и `docs/workflow/work-log.md`, создаёт ветку `role/<role>/TASK-NNN-<slug>` и коммитит оформление.
3. Orchestrator назначает исполнителя, затем независимую проверку выполняет `qa-tester`; при `FAIL` — до 3 кругов исправлений.
4. В итоге открывается Pull Request. Владелец делает ревью, слияние и приёмку.

Процедура описана в `.claude/skills/task-intake/SKILL.md`.

## Статусы
`BACKLOG` → `READY` → `IN_PROGRESS` → `REVIEW` → `DONE` (также `BLOCKED`, `CANCELLED`). Статус `DONE` ставится только после приёмки владельцем.

## Файлы
- `TASK-NNN.md` — постановка, допущения, критерии приёмки и отчёт о выполнении.
- Отчёты независимой проверки — в `docs/qa/`.
