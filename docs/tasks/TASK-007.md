- **ID:** TASK-007

- **Зависимости:** TASK-004, TASK-005, TASK-006 (слиты в `main`). Ветка `role/bitrix-developer/TASK-007-stage3-home` от `main`.

## Цель
Главная `/` собрана из секций V4 (`prototype/homepage-v4/index.html`); повторяющиеся данные берутся из инфоблоков, одиночные тексты и картинки — из областей включения, товары — из каталога. Рендер каждой секции проверяет владелец до следующей.

## Область изменений
Разрешено: `backend/www/index.php`, `backend/www/include/fk_home_*.php`, `backend/www/local/**` (шаблоны компонентов, `css/`, `js/`, `forkel:solutions.slider`), `docs/**`. Запрещено: ядро, `prototype/`, шаблон шапки и подвала (кроме подключения CSS/JS).

## Общие правила
- Страница задаёт `fk_no_hero = Y` (у главной свои секции). Классы V4 (`hero`, `sec`, `split`, `dirs`, `feat`, `nums`, `pro`, `fin` и др.) уже в `styles.css` шаблона.
- Одиночный текст/картинка → `bitrix:main.include` с файлом `/include/fk_home_<имя>.php`. Список → инфоблок. Товары → `catalog.section`. Секцию без данных не выводим пустой.
- Секция «Подбор» не переносится (В-6): вместо неё — блок-ссылка не выводится, пока подбор отложен.
