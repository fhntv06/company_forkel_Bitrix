# TASK-001

## 1. Основная информация

- **ID:** TASK-001
- **Название:** Уменьшить размер шрифта h1 по всему прототипу V4 в 1,5 раза
- **Статус:** IN_PROGRESS
- **Приоритет:** P2
- **Ответственная роль:** UI Implementation
- **Источник:** сообщение владельца в чате (`/task`)
- **Зависимости:** нет (PRT-003 закрыт)

## 2. Цель

Все заголовки первого уровня (h1) страниц `prototype/homepage-v4/` должны иметь размер шрифта в 1,5 раза меньше текущего на любой ширине окна.

## 3. Контекст

Размер h1 задаётся несколькими независимыми правилами `clamp()` (проверено чтением кода и `grep` по `*.css`, `*.html`, `*.js`):

| Где используется | Правило | Сейчас |
|---|---|---|
| `index.html` (`#h1`), `collection.html` и h1 в `project.js` (`.fk-page-title`, у которого `font-size` закомментирован в `css/page.css`) | `h1` в `styles.css:41` | `clamp(4rem, 1.2rem + 3.6vw, 8rem)` |
| catalog, new, projects, contacts, cart, checkout, account, favorites, search, configurator, cooperation, about | `.fk-ab-hero__title` в `css/about.css:5` | `clamp(1.875rem, 1.2rem + 2.6vw, 3.5rem)` |
| обложка страницы проекта (`project.js`) | `.fk-prj-cover__text .fk-page-title` в `css/projects.css:379` | `clamp(1.75rem, 1rem + 2vw, 3rem)` |
| страница товара и состояние «Товар не найден» (`shop.js`) | `.fk-pdp__title` в `css/product-page.css:12` | `var(--fk-fs-h2)` = `clamp(1.6rem, 1.1rem + 1.8vw, 2.6rem)` |

Токен `--fk-fs-h2` используется и у настоящих h2, поэтому токен не меняется, правится только правило `.fk-pdp__title`.
Состояние «Проект не найден» (`project.js:23`) использует `.fk-page-title` вне обложки → глобальное правило `h1`.

Связанные требования и решения: ограничений на размер h1 в `requirements.md`/`decisions.md` для V4 не найдено (см. «Допущения»).

## 4. Область изменений

### Разрешено изменять
- `prototype/homepage-v4/styles.css` (только правило `h1`)
- `prototype/homepage-v4/css/about.css` (только `.fk-ab-hero__title`)
- `prototype/homepage-v4/css/projects.css` (только `.fk-prj-cover__text .fk-page-title`)
- `prototype/homepage-v4/css/product-page.css` (только `.fk-pdp__title`)
- `docs/tasks/TASK-001.md`, `docs/workflow/task-queue.md`, `docs/workflow/work-log.md`, `docs/qa/` (отчёт QA)

### Разрешено только читать
- остальной `prototype/homepage-v4/`, `docs/`

### Запрещено
- Менять V1–V3, токены, h2/h3, межстрочный интервал, вес, letter-spacing, разметку, JS, зависимости, архитектуру.

## 5. Требуемый результат

Минимальная правка четырёх правил: каждое значение `clamp()` (min, коэффициент vw, смещение rem, max) делится на 1,5.

## 6. Критерии приёмки

- [ ] `getComputedStyle(h1).fontSize` в 1,5 раза меньше значения на `main` (допуск ±0,5 px) на ширинах 360, 768, 1280, 1920 px для: index, catalog, collection, project, product, cart, about и остальных страниц с h1.
- [ ] Диф затрагивает только 4 правила размера h1 и документацию задачи.
- [ ] Размер h2/h3 и остальных элементов не изменился.
- [ ] Нет горизонтальной прокрутки на 360 px на проверенных страницах.

## 7. Ограничения

Только `font-size`. Если после уменьшения нужен пересмотр line-height/отступов — отдельное согласование.

## Допущения

1. «В 1,5 раза» применяется ко всем значениям `clamp()` пропорционально, поэтому соотношение на любой ширине окна ровно 1/1,5.
2. «Весь сайт» = все страницы V4 и h1, генерируемые JS (товар, проект, состояния «не найдено»).
3. Минимальный размер h1 на мобильных станет 17–20 px (у товара ≈17 px, у страницы проекта ≈19 px) — прямое следствие требования ÷1,5; при необходимости владелец может задать нижнюю границу.
4. Токены и отступы не меняются.
