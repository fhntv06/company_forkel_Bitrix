## 2. Цель

## 3. Контекст

- В прочитанном `prototype/homepage-v4/contacts.html` уже есть обычный h1 «Контакты» (#ct-title), баннера и заголовка «Связь» нет. Сохранить это состояние.
- В .fk-ct-channels находятся телефон, email, адрес и график работы. В карточке адреса пока «Уточняется». Ниже расположены кнопки связи; также есть заглушка карты и реквизиты.
- Требование UI-006 предусматривает контактную информацию. По DEC-007 неподтверждённые контакты нельзя придумывать; адреса для этой задачи взяты из указанного владельцем источника.
- На странице LEDRON есть пять уникальных точек: два магазина EXPOSTROY, офис, магазин «Каширский двор» и склад. Офис не входит в запрошенные четыре адреса. Повторы адресов в разметке источника не являются дополнительными точками.

### 5.2. Размещение

1. После основных способов связи добавить секцию «Магазины и склад» с четырьмя компактными карточками в порядке таблицы.
2. У каждой карточки показать тип точки, название и полный адрес. Различать два магазина EXPOSTROY по павильонам.
3. Вместо существующего «Адрес — Уточняется» сделать ссылку «Адреса магазинов и склада» на новую секцию; не оставлять противоречащую заполненным адресам заглушку.
4. Выровнять секцию по контейнеру и сетке проекта. Рекомендуемая сетка: две колонки на широком экране и одна на узком, с существующими отступами и типографикой.
5. Адреса показывать полностью, с естественными переносами; без многоточия, обрезки и фиксированной высоты, скрывающей текст.
6. Сохранить единственный h1 «Контакты», текущие способы связи, кнопки, карту и реквизиты. Не возвращать баннер или заголовок «Связь».
7. Проверить размещение соседних элементов .fk-ct после добавления секции; не полагаться на прежний порядок дочерних элементов без проверки CSS.
