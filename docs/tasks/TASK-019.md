## 2. Цель

Привести настройки доставки и платёжных систем в Beta-сборке 1С-Битрикс в точное соответствие с подтверждёнными решениями заказчика от 2026-11-27:

- заменить тестовый обработчик `yandexcheckout` на эквайринг **Альфа-Банка** (карты + СБП) в тестовом/sandbox-режиме с параметрами из `.env`, готовым к подстановке боевых ключей.

## 5. Требуемый результат

### 5.1. Доставка: Курьер, Самовывоз, Отправка ТК (`DEC-010`)
- В `b_sale_delivery_srv` и миграции `sprint.migration`:
  - Переименовать активную службу `ID=6` из `«СДЭК (до пункта выдачи или курьером)»` в **`«Отправка транспортной компанией (ТК)»`** (описание: отправка транспортными компаниями по РФ — СДЭК, Деловые Линии, ПЭК и др.; условия согласуются с менеджером).
  - Сохранить остальные 2 активные доставки без изменений: **Курьерская доставка** и **Самовывоз из магазина или склада** (4 точки `b_catalog_store`).
  - Проверить на `/personal/order/make/`, что отображаются ровно 3 доставки: Курьер, Самовывоз, Отправка ТК (без дублей).

### 5.2. Платёжный провайдер: Альфа-Банк (`DEC-013`)
- Подключить и настроить в 1С-Битрикс (`sale`) **интернет-эквайринг Альфа-Банка** (карты Мир/Visa/Mastercard + **СБП**) вместо `yandexcheckout`:
  - Использовать официальный модуль/обработчик Альфа-Банка для Битрикс (либо собственный обработчик `local/php_interface/include/sale_payment/alfabank/` поверх REST API Альфа-Банка `register.do` / `getOrderStatusExtended.do` с поддержкой СБП).
  - Вынести параметры подключения в `backend/.env` (`ALFABANK_USER`, `ALFABANK_PASSWORD` или `ALFABANK_TOKEN`, `ALFABANK_TEST_MODE=1`, `ALFABANK_CALLBACK_SECRET`, `ALFABANK_FFD_ENABLED=0`) и отразить их в `backend/.env.example`.
  - В `b_sale_pay_system_action`:
    - Перевести онлайн-оплату банковской картой и оплату через СБП на обработчик **Альфа-Банка** (в тестовом/sandbox-режиме до получения боевых ключей).
    - Сохранить **«Оплата при получении (наличные / карта курьеру)»** и **«Безналичный счёт для юридических лиц»**.
    - Деактивировать неиспользуемые профили `yandexcheckout`.
  - Адаптировать `local/ajax/payment_webhook.php` (проверка подписи/секрета callback Альфа-Банка + верификация статуса через `getOrderStatusExtended.do`, автосмена статуса оплаты только при подтверждении `orderStatus === 2` / `DEPOSITED`) и страницу возврата `/personal/order/payment/` (успех, отказ, отмена, повтор оплаты).
  - Оформить изменения через воспроизводимую миграцию `sprint.migration`.

### 5.3. Ограничения по соцсетям и текстам (`DEC-011`, `DEC-012`)
- Проверить, что `fk_social_vk.php`, `fk_social_tg.php`, `fk_social_max.php` остаются пустыми и виджет/блок соцсетей не показывает битых ссылок.
- Не менять тексты страниц; убедиться, что тексты по-прежнему редактируются через включаемые области в админке.
