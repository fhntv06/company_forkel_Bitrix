### 4.3. Прототип V2 (`prototype/homepage-v2/`, обновлено 2026-10-18)

Самостоятельная версия на основе V1: визуально усиленная главная, каталог, страница товара, корзина, подбор. Принята владельцем как визуальная основа (приёмка QA не проводилась).

- **Подбор (на главной):** коллекция → тип изделия → цвет рамки → цвет механизма; шесть цветов в каждом наборе; превью из двух слоёв (`prototype/assets/images/`, 12 файлов, соответствие цветам — `about_photo.md`); комплект добавляется в корзину **одной позицией «Комплект»**. Правила совместимости неизвестны, в демо доступны все сочетания.
- **Корзина:** `localStorage` (ключ `fk-demo-cart-v1`), счётчик в шапке, количество 1–99; демо.
- **Проверено** (Chromium, Playwright, 360/768/1024/1440 px): нет горизонтальной прокрутки и ошибок консоли, основные сценарии добавления и пересчёта. Независимая приёмка не проводилась; не проверялись реальные устройства, Safari, Firefox, скринридеры.
