## 6. Правила обновления

После завершения задачи:
1. Обновить общий статус и текущий этап.
2. Отразить только подтверждённые результаты.
3. Указать незавершённые задачи и блокеры.
4. При необходимости сослаться на подробную запись в `work-log.md`.
5. Не копировать сюда подробные логи, списки всех изменений и полное описание требований.
