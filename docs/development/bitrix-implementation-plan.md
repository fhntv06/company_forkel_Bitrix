## Как будем работать

Для каждой секции указано три вещи:
- **Данные** — откуда берутся: инфоблок, меню, область включения (`include`), компонент Битрикса или остаётся в шаблоне.
- **Вы (админка)** — что создать или заполнить. Пока вы не подтвердите, что готово, я пишу код только на стабильные коды (символьные коды инфоблоков, свойств, меню), которые укажу в задании.
- **Я (код)** — шаблон компонента, вёрстка из V4, подключение стилей и скриптов.

Общие правила выбора источника данных:
1. Повторяющиеся элементы (карточки, слайды, преимущества, пункты списков) → **инфоблок**.
2. Один-единственный текст или картинка на странице → **область включения** (`bitrix:main.include`, файл в `include/`), правится в админке в визуальном редакторе.
3. Навигация → **меню** (`bitrix:menu`, типы меню).
4. Контакты и реквизиты компании → области включения в `include/` (один источник, выводится и в шапку, и в подвал, и на «Контакты»).
5. Товары, заказы, пользователи → штатные модули (`catalog`, `sale`, `main`); своего хранилища не заводим.
6. Что нельзя настроить штатно (подбор комплекта, слайдер с точками-товарами) → собственный компонент в `local/components/forkel/`.

## Реестр инфоблоков (что создать в админке)

Тип инфоблока `forkel` (Контент → Инфоблоки → Типы инфоблоков), дальше инфоблоки. Символьные коды — предлагаемые, их подтверждаете вы.

| Код | Название | Элементы | Ключевые свойства | Где используется |
|---|---|---|---|---|
| `catalog` | Каталог | Товары; разделы = **категории** (Розетки, Выключатели, Рамки, Управление жалюзи, Терморегуляторы, Диммеры) | `COLLECTION` (привязка к `collections`), `MATERIAL` (список), `MECHANISM_TYPE`, `NEW` (флаг «Новинка»), `MANUAL` (файл инструкции), `MODEL_3D`, `VIDEO`, `ARTICLE` | Каталог, товар, новинки, поиск, подбор |
| `catalog_offers` | Торговые предложения | Варианты товара по цвету | `COLOR` (список: белый, чёрный, серый, светло-серый, кашемир, золотой), артикул, цена, остаток через модуль `catalog` | Товар, карточки, подбор |
| `collections` | Коллекции | F70, F55 | `PALETTE` (допустимые цвета), `MATERIALS` (допустимые материалы), обложка, описание | Главная, каталог, страница коллекции, подбор |
| `projects` | Проекты | Проект | обложка, галерея (множественное), описание, дата | Главная, «Проекты», страница проекта, поиск |
| `solutions` | Готовые решения | Слайд (фото) | `HOTSPOTS` (множественное свойство: привязка к товару + координаты X/Y в %) | Главная |
| `interiors` | Интерьеры | Карточка | фото, название, описание | Главная |
| `features` | Особенности | Три карточки («Soft Touch», «Автозажим», «Одна серия») | иконка/картинка, текст | Главная |
| `pro` | Профессионалам | Дизайнеры, монтажники, дилеры | текст, ссылка | Главная, «Сотрудничество» |
| `leads` | Заявки | Обратная связь, звонок, анкета партнёра | поля формы, тип заявки, согласие | Формы (см. В-4) |

Меню (Контент → Структура сайта → редактирование меню или `.<тип>.menu.php`): `top` (шапка), `catalog` (панель каталога: коллекции + категории строятся из инфоблоков, ручное меню не нужно), `footer_sections`, `footer_info`, `left` (личный кабинет).

Области включения (`backend/www/include/`): `phone.php`, `email.php`, `address.php`, `schedule.php`, `requisites.php`, `socials.php`, `copyright.php`, `legal_link.php` и т. д. — по одному файлу на значение.
