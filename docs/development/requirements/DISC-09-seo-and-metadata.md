# DISC-09 — SEO and Metadata

## 1. Purpose

Документ определяет требования к поисковой оптимизации, метаданным, индексированию и технической доступности страниц интернет-магазина FORKEL на 1С-Битрикс.

## 2. URL structure

Для каждой индексируемой страницы определить:
- Канонический URL.
- Правило формирования URL.
- Требования к уникальности адреса.
- Обработку неизвестных страниц.
- Правила редиректов при необходимости.

Фактическая структура URL должна быть согласована до релиза. Сначала проверить штатные настройки ЧПУ, шаблоны URL и SEO-свойства Bitrix; собственную маршрутизацию реализовывать только при недостаточности штатных механизмов.

## 3. Metadata

Для каждой индексируемой страницы определить:
- Уникальный Title.
- Meta Description.
- Canonical URL.
- Правило формирования заголовка H1.
- Open Graph metadata, если применимо.

Метаданные должны соответствовать реальному содержанию страницы. Проверить штатные поля и шаблоны SEO Bitrix для разделов, товаров и торговых предложений; не создавать параллельный механизм метаданных без необходимости.

Не создавать фиктивные ключевые слова, описания услуг или географические привязки.

## 4. Indexability

Определить:
- Какие страницы индексируются.
- Какие страницы исключаются из индексации.
- Требования к robots.txt.
- Правила генерации sitemap.xml.
- Какие настройки/механизмы Bitrix уже реализованы в установленной версии и какие требуют доработки.
- Поведение для страниц с ошибками.
- Необходимость исключения технических и тестовых окружений.

Поисковая выдача и индексирование не должны раскрывать закрытые или служебные данные.

## 5. Structured data

Проверить применимость структурированных данных для подтвержденного типа бизнеса и содержимого страниц.

Использовать только соответствующие фактическим данным типы и свойства.

Не добавлять неподтвержденные рейтинги, адреса, цены, отзывы или другие сведения.

## 6. Images

Проверить:
- Осмысленные имена файлов, если управляемы.
- Alt-тексты.
- Оптимизацию размеров и форматов.
- Правила загрузки изображений.
- Отсутствие значимого контента только внутри изображений без текстового представления.

## 7. Projects SEO

Для страниц проектов определить:
- Стабильные URL.
- Уникальные заголовки и описания.
- Правила отображения проекта при прямом переходе по URL.
- Обработку удаленных и неизвестных проектов.
- Правила включения в sitemap.

## 8. Search and duplicate content

Если поиск использует параметры URL, определить, должны ли такие URL индексироваться.

Предусмотреть согласованную обработку дублирующегося контента и canonical metadata.

## 9. SEO validation

Перед запуском проверить:
- Уникальность основных метаданных.
- Корректность заголовков.
- Доступность индексируемых страниц.
- Работу sitemap и robots.txt.
- Отсутствие случайных запретов индексации.
- Корректность canonical URLs.
- Работу редиректов, если они необходимы.
- Отсутствие тестового контента.
